# 🌍 AI Travel Planner

An intelligent AI-powered travel planning web application that helps users create personalized travel itineraries in seconds. Simply enter your destination, travel dates, budget, and preferences, and let AI generate a complete travel plan with attractions, accommodations, restaurants, transportation, and interactive maps.

## ✨ Features

- 🤖 AI-generated personalized travel itineraries
- 📍 Interactive maps and location search
- 🏨 Hotel recommendations
- 🍽️ Restaurant suggestions
- 🎯 Tourist attraction recommendations
- 💰 Budget-based trip planning
- 📅 Day-wise travel schedule
- 🌦️ Weather information
- 🚗 Transportation suggestions
- 📱 Responsive and modern UI
- ⚡ Fast and user-friendly experience

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- React
- AI Studio
- Google Maps API
- Gemini AI API (or your preferred AI model)

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/yourusername/ai-travel-planner.git
```

2. Navigate to the project

```bash
cd ai-travel-planner
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```
